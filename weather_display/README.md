# 太阳能相变粮食干燥 - 联网气象监测系统

基于 **ESP32-S3-N16R8** + **2.8寸 SPI TFT（带 GT24L24A2W16 字库芯片）** 的 Arduino IDE 项目：联网获取实时天气并显示在 TFT 上，作为太阳能干燥决策依据。

---

## 1. 硬件清单

| 部件 | 说明 |
|---|---|
| 主控 | ESP32-S3-WROOM-1 (N16R8, 16MB Flash / 8MB PSRAM) |
| 显示屏 | 2.8寸 SPI TFT，240×320，**带字库**（GT24L24A2W16） |
| 编程环境 | Arduino IDE 2.x + ESP32 Arduino Core ≥ 2.0.14 |

---

## 2. 模块接线（ESP32-S3 ↔ 2.8寸带字库 TFT）

```
ESP32-S3          TFT 模块 (2.8寸带字库)
─────────         ─────────
  3V3   ────────  VDD     （模块 3.3V 供电，原理图 R8=0R 短路）
  GND   ────────  GND
  GPIO 11 (MOSI) ── SDI
  GPIO 13 (MISO) ── SDO    （字库数据输出；若屏不带字库可悬空）
  GPIO 12 (SCK)  ── SCL
  GPIO 10 (CS)   ── CS     （低电平=液晶，高电平=字库，复用同一脚）
  GPIO  9 (DC)   ── RS / DC
  GPIO 14 (RST)  ── RST
  GPIO 21 (BLK)  ── BLK    （背光；**勿用 GPIO45/46**——它们是 VDD_SPI strap 引脚，接了会导致无法上传！）
  GPIO  0 (BOOT) ── 按钮    （按下立即刷新天气，可选）
```

> **关于 CS**：本模块通过同一 CS 引脚复用液晶（低电平选中）和字库（高电平选中），原理图上有电平转换。代码已自动处理。

> **关于 SDO**：字库芯片的 SO 输出。若屏版本"不带字库"则 SDO 脚为空，但仍建议保留接线，便于兼容。

## 3. Arduino IDE 配置

1. **安装 ESP32 Arduino Core**
   - 文件 → 首选项 → 附加开发板管理器 URL：
     `https://espressif.github.io/arduino-esp32/package_esp32_index.json`
   - 工具 → 开发板 → 开发板管理器 → 搜索 `esp32` → 安装 `esp32 by Espressif Systems` (≥ 2.0.14)

2. **无需安装任何第三方库**
   - JSON 解析使用代码内置的极简提取器，WiFi/HTTPClient/SPI 均为 ESP32 内置。

3. **开发板设置**
   - 工具 → 开发板：`ESP32S3 Dev Module`
   - 工具 → USB CDC On Boot：`Enabled`（首次烧录用）
   - 工具 → Flash Size：`16MB (128Mb)`
   - 工具 → PSRAM：`OPI PSRAM`
   - 工具 → Upload Speed：`921600`
   - 工具 → Port：选择 ESP32-S3 对应 COM 口

## 4. 用户配置

打开 `weather_display.ino`，修改配置区：

```cpp
const char* WIFI_SSID     = "你的WiFi名";
const char* WIFI_PASSWORD = "你的WiFi密码";

// 城市：改 CITY_INDEX 切换，0=北京，1=上海，2=广州 …
// 也可仿照格式新增城市（UTF-8 用于 API，GBK 用于字库显示）
const uint8_t CITY_INDEX = 0;
```

### 天气 API（默认 itboy，纯 HTTP）+ 自动定位

默认使用 **itboy 天气**：`http://t.weather.itboy.net/api/weather/city/<城市代码>`
- **纯 HTTP**（无 HTTPS/TLS，手机热点也能稳定连接）、免 Key、返回全中文

**自动定位（默认开启）**：
- 上电后先通过 `whois.pconline.com.cn`（纯 HTTP）查询公网 IP 归属地 → 得到当前城市
- 与内置城市表（50 个城市，含所有省会 + 主要城市）匹配 → 显示该城市天气
- 匹配失败或定位失败 → 回退到 `CITY_INDEX` 指定城市
- 每 15 分钟刷新时会重新定位（手机换地方了会自动跟着变）

**默认城市（兜底）**：`CITY_INDEX` 已设为 **42 = 唐山**（唐山工业职业技术大学所在地：河北省唐山市曹妃甸新城）。自动定位失败时显示唐山天气。

**关闭自动定位**：把 `#define AUTO_LOCATE 1` 改成 `0`，则固定显示唐山天气。
**新增城市**：按 `CITIES[]` 格式补一行（`名称, 中国天气网代码, GBK 字节`），GBK 字节用 `_gbk_gen.py` 生成。

## 6. 操作

- **上电**：自动连接 WiFi → NTP 同步 → 拉取天气 → 渲染。
- **BOOT 按键 (GPIO0)**：按下立即刷新天气。
- **自动刷新**：每 15 分钟拉取一次天气。
- **时间刷新**：每秒更新屏幕底部时间。

## 7. 常见问题

| 现象 | 排查 |
|---|---|
| 白屏 | 检查 RST 是否接好；调换 0x36 的旋转参数 (0x28 / 0xA8 / 0x68 / 0xE8) |
| 中文乱码 / 显示方框 | 检查 SDO 是否接到 GPIO13；确认模块"带字库"版本 |
| 联网失败 | 确认 WiFi 账号密码；屏幕显示"连接失败/请检查WiFi" |
| 时间不更新 | NTP 需要联网，初次同步可能 1~5 秒 |
| 天气接口失败（HTTP -1） | 检查热点/网络；itboy 是纯 HTTP，一般稳定；仍不行换和风天气（dev.qweather.com 注册免费 key） |
| 城市列表里没有 | 仿照 CITIES[] 格式补一行（用 `_city_gen.py` 生成字节） |

## 8. 字库芯片速查

| 区段 | 偏移 | 大小 |
|---|---|---|
| ASCII 8×16 | 0x00080800 | 16 字节/字符 |
| ASCII 16×32 | 0x00082600 | 64 字节/字符 |
| GBK 16×16 | 0x0011DD00 | 32 字节/汉字 |

读命令：`0x03 + 地址24bit + 0xFF * N`（SPI 全双工读 N 字节）。

## 9. 自定义中文字符串

若需添加新汉字，使用 `_gbk_gen.py` 生成 GBK 字节：

```bash
python _gbk_gen.py "气象监测" "太阳能相变"
```

将输出的 `{0xC6,0xF8,...}` 拷贝进 `TXT_xxx` 数组即可。

### 无线光照显示（ESP32-C3 ×4 + GY-30 → ESP32-S3）

天气屏底部以 **2×2 网格**实时显示 **4 个 C3 节点**的光照强度（lux）和在线状态：

```
┌──────────────────────┐
│ ●节点1 1364lux  ●节点2 1200lux │
│ ●节点3  980lux  ●节点4  离线   │
└──────────────────────┘
● 绿=在线，红=离线(>10s)
```

- **节点序号**：每个 C3 改 `#define NODE_ID 1`（烧录时分别设为 1、2、3、4），数据包格式 `LUX<序号>:数值`
- **通信**：所有设备连同一 WiFi，C3 通过 **UDP 广播**（端口 8266）每秒发送光照值
- **离线判定**：某节点超过 10 秒收不到数据，该节点变红并显示 `--`
- **接线（GY-30 → C3）**：VCC→3.3V、GND→GND、SDA→GPIO8、SCL→GPIO9

> 注意：`weather_types.h` 必须在 sketch 目录里与 `weather_display.ino` 同目录，Arduino IDE 会自动把它加入编译。
